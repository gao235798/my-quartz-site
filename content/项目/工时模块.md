### 2. 开发需求
- [x] 配置工序是否强制派工
- [x] 在制令页面默认加载派工人员信息，可以修改，写入派工人员
- [x] 在工序页面选择人员信息，用来默认的派工人员信息
    - [x] 在派工页面可以借调人员
- [ ] 无定额派工   
- [ ] 无定额报工，可以选择工单，工序去报工记录下来
- [x] 上线的时候如果强制派工的工序，没有派工，不允许上线
- [x] 如果强制派工的工序派了工人，每天定时计算工时数据
- [ ] 月度回复钉钉工时信息
- [ ] 获取人员信息
- [ ] 一个人正常派工只能在一个工序上班，如果涉及多个工序只能在借调应用中使用，借调的人员会影响工时系数，在报工中去除
